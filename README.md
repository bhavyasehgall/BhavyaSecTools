# BhavyaSecTools

**BhavyaSecTools** is a Python-based collection of practical cybersecurity utilities developed as part of my hands-on cybersecurity learning and security-tool development.

The project brings together small security-focused utilities for areas such as **network reconnaissance, decoding, steganography, web detection, and security automation** through a simple interface.

The goal is to build practical tools while strengthening Python, Linux, and cybersecurity fundamentals.

---

## ⚠️ Authorized Use Only

These tools are intended for:

* Personal cybersecurity labs
* CTFs
* Security learning
* Systems you own
* Authorized security testing

Do not use the tools against systems, networks, or data without permission.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/bhavyasehgall/BhavyaSecTools.git
cd BhavyaSecTools
```

Make sure Python 3 is installed:

```bash
python3 --version
```

Depending on the utility being used, additional system tools or Python packages may be required.

---

## ▶️ Running the Project

Run the main application:

```bash
python3 main.py
```

Individual utilities can be executed separately where supported.

For example:

```bash
python3 decoder.py
```

Check the source code of each utility for its specific requirements and usage.

---

## 🔐 Security Considerations

Some utilities interact with security-sensitive functionality or external command-line tools.

Before using a utility:

1. Understand what it does.
2. Test it in a controlled environment.
3. Avoid using it against unauthorized systems.
4. Do not use it to access data you do not own.
5. Keep dependencies updated.
